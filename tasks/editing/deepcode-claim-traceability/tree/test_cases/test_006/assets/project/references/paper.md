# Cited transform score

EQ-K6 defines `score(x) = kappa(x) / (1 + abs(kappa(x)))`.

CITE-K6 states that kappa is defined in SYN-CITE-17. That cited document and its
definition are not included here. GAP-K6 is the missing definition.

CLM-K6 states that the score lies between -1 and 1, but numerical
reproduction requires the unavailable kappa. No seed or runnable experiment
protocol is specified.
