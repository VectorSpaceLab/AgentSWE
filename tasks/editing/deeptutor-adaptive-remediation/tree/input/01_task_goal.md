# Task goal

Edit the supplied pinned DeepTutor repository so its real mastery-path tutor can
turn cautious diagnosis into persistent, learner-visible remediation and can
recover honestly across retries, restarts, concurrent clients, and provenance
checks.

Your edit must preserve ordinary mastery behavior while making the registered
mastery tools support adaptive remediation delivery, review planning, ordered
learning events, session handoff, policy versioning, bounded learner snapshots,
snapshot attestation/restore, an append-only witness ledger, and read-only
witness-chain audit.

The final behavioral target is the DeepTutor lower agent, not a standalone
script. A model-driven mastery turn must be able to inspect the active path,
select and call the patched product tools, ground its learner recommendation in
the resulting persistent state, and refuse unsafe or unverifiable recovery.

Do not replace DeepTutor with another agent, hard-code public cases, or solve the
task by emitting canned final answers.
