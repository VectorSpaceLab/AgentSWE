# Resources

The isolated Candidate runtime receives evaluator-owned broker endpoints in `HARNESS_RESPONSES_URL`, `HARNESS_SEARCH_URL`, and `HARNESS_VISIT_URL`. `GATEWAY_RESPONSES_URL`, `OPENAI_BASE_URL`, and `SERPER_URL` are compatible aliases. The runtime also provides placeholder values in `GATEWAY_API_KEY`, `OPENAI_API_KEY`, and `SERPER_TOKEN`; these authenticate only to the broker and are not resource secrets. Do not hard-code upstream URLs. A search request is JSON of the form `{"query":"...","page":1,"search_type":"search","token":"$SERPER_TOKEN"}`. A visit is `POST $HARNESS_VISIT_URL` with `{"url":"https://..."}` and `Authorization: Bearer $GATEWAY_API_KEY`; direct Candidate internet access is disabled. The model is evaluator-locked to `gpt-5.6-sol`. The frozen evaluator uses the pinned BrowseComp split and an evaluator-owned fixed judge; per-row budgets are 20 model calls, 20 searches, and 20 visits.

Real credentials are mounted only into the evaluator-owned broker. The Candidate cannot read them. The public development package contains no secret values. The evaluator independently records and enforces actual model calls, searches, visits, wall time, and provider failures through authenticated broker statistics.
