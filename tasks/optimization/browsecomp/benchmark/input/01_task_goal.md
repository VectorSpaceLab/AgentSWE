# BrowseComp Search Harness Optimization

You are optimizing the runnable Basic Search ReAct agent already installed in the submission workspace. You are not starting from an empty submission and you are not solving one fixed example.

## Goal

Improve the supplied search agent so it generalizes to unseen BrowseComp rows. Preserve the uniform CLI while improving search planning, source inspection, evidence reconciliation, recovery and final answer extraction.

## Non-goals

- Do not hard-code the provided development cases or hidden answers.
- Do not submit self-reported rewards as authoritative evidence.
- Do not copy a complete third-party agent or evaluator as the solution.
