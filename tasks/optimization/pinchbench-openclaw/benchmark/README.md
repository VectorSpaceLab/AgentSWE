# PinchBench OpenClaw Productivity Optimization

## v3 optimization protocol

The Builder optimizes a runnable OpenClaw Basic Productivity Agent. The audited stratified split is 20 public development and 40 hidden tasks. See `task_contract.json` and `meta/eligibility_audit.json`.

This compact case freezes eight public PinchBench task specifications into three dev and five hidden rows. It preserves the task prompts and selected public assets but keeps grading criteria and source task files evaluator-owned.
