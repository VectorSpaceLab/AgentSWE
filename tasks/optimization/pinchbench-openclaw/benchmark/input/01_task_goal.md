# PinchBench OpenClaw Productivity Harness Optimization

You are optimizing the runnable OpenClaw Basic Productivity Agent already installed in the submission workspace. You are not starting from an empty submission and you are not solving one fixed example.

## Goal

Build a reusable tool-using productivity agent that completes file, calendar, analysis, browser, research, and codebase tasks in a controlled workspace, including recovery and cross-step planning.

## Non-goals

- Do not hard-code the provided development cases or hidden answers.
- Do not submit self-reported rewards as authoritative evidence.
- Do not copy a complete third-party agent or evaluator as the solution.
