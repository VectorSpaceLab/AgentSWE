# Reserve an Accessible Theater Pair

## Case

- Case ID: `test_006`
- Application: [Cobalt Community Theater Seat Map](assets/serve.py)
- Viewport: 1180 x 820 pixels
- Corpus: closed. Seat availability, companion relationships, sightline markers, and stage orientation are authoritative as rendered on the seat-map canvas and legend.

## Goal

Reserve one wheelchair space and its immediately adjacent companion seat for the `Saturday 19:30` synthetic performance. The pair must be in the front half, have an unobstructed sightline, and be closest to the east exit among valid available pairs. Runtime availability changes per fixture launch.

Use the canvas and legend, select the two coordinates, choose accessibility option `Aisle transfer assistance`, and decline printed tickets. An interruption modal may warn about a separated pair or blocked sightline; recover by clearing only the invalid selection and choosing the correct adjacent pair. Review the exact seat labels shown by the application.

## Completion

Confirm exactly once. The receipt must list the correct runtime-selected wheelchair/companion pair, Saturday 19:30, aisle transfer assistance, digital delivery, and reservation status Confirmed. Do not select ordinary seats, a rear-half pair, an obstructed pair, or any seat for another performance.
