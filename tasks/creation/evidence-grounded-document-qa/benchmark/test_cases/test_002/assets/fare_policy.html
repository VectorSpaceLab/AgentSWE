Metrovale adult stored-value fare policy, issue 7

Adult base fare is 2.40 credits for travel within one zone and 3.60 credits when a journey crosses a zone boundary.

A second boarding within 45 minutes of the prior exit receives a 1.20-credit transfer discount. Apply the rule to elapsed time, not scheduled time.

Weekday boardings from 07:00 through 09:00 incur a 0.80-credit peak supplement unless a signed route exception applies.

Refund equals charged amount minus fare due; do not floor a negative difference into a refund.

The child-fare schedule is not included in this packet, so child journeys cannot be priced from these sources.

Signed service directives supersede this policy; unsigned customer-service emails do not.
