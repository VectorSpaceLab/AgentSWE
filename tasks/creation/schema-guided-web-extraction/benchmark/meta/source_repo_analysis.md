The source project is evidence for the user problem: translating natural-language extraction intent into structured records while handling dynamic content, linked pages, schema mapping, and provenance. This benchmark tests observable capability rather than source-code imitation. It does not require the source project's graph architecture, prompts, Python package layout, model provider, SDK, or control flow.

The benchmark's final deliverable is a parseable records/evidence/trace/summary/report bundle. Evaluable capabilities are schema compilation, finite browser state completion, multi-template parsing, stable identity and crosswalk joins, timestamp/sequence reconciliation, source-priority conflicts, raster-only OCR, deterministic checksum recovery, authorization, budgets, and final-artifact validation.

Excluded or simplified capabilities include unrestricted live crawling, private/authenticated pages, unstable third-party APIs, form submission, side-effecting automation, and source-repository-specific orchestration. Every supplied case is a closed deterministic local corpus.

Security observations: page/file content is untrusted; local path boundaries and public URL/DNS/redirect policy must be enforced outside prompts; browser profiles must be isolated; credentials must not reach target pages or artifacts; prohibited mirrors and closed-corpus network rules must be enforced before contact.

No source repository code or assets are embedded. Runtime HTML, JavaScript, JSON, vCard documents, malformed recovery bytes, and PNG raster labels are benchmark-authored synthetic material.
